Hello everyone! I'm Sanjana S, a 1st year Btech student who's passionate about Mathematics, AI and music. I also enjoy problem-solving and learning about technology.

ABOUT THIS PROJECT:
This is a personal portfolio website built using HTML5 and CSS3 which showcases my background, skills, projects, education and contacts. This project was created as part of my learning journey in web development. The webpage has a simple and clean UI design. The website consists of 4 sections: Home, Profile, Education and Contacts.

Website Structure:
The website consists of the following pages- 1. Home (index.html)
2. Profile (profile.html)
3. Education (education.html)
Home section contains introduction and a bit about myself, Profile section contains skills, projects, achievements and contact details. Last but not the least, the education section contains education timeline in a clean and structured format.

Styling:
Each page has its own CSS stylesheet- 1.Home (index.css)
2. Profile (profile.css)
3. Education (education.css)

Navigation & Responsiveness:
A navigation bar is included in home page to navigate through the 4 sections of the webpage
Moreover, the page is made responsive for smaller sized devices
